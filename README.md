# Telefono — removed from the catalog

This repository used to profile **Telefono** as an API provider. There is no such provider: the
company, its documentation host and its API host do not exist. Telefono's domain is parked or
unanswered, `developers.telefono.com` and `api.telefono.com` have no DNS record, and the OpenAPI
contracts published here described endpoints nobody runs.

It was removed on **2026-09-23** as a catalog-hygiene correction
([api-evangelist/roadmap#597](https://github.com/api-evangelist/roadmap/issues/597)).
Nobody requested it; nothing about any company was published here.

- **What remains:** this notice only. There is no provider page and no rating.
- **Registry:** the slug is in `api-search/network/_data/delisted.yml`, which stops every
  harvest and enrichment pipeline from re-creating the record.
